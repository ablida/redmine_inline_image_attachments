# redmine_issue_copy_relations

When clicking the download icon on attached images, the browser will usually download the image.

With this plugin installed, it will instead display the image in a browser tab.

If the normal redmine preview (what you get when clicking on the file name) is not enough for you.

Undoes this security patch, please beware. https://www.redmine.org/projects/redmine/repository/svn/revisions/16285
